# Operator output test

`operator-test.wav` is an offline spoken output test: "FLUX operator output test. One, two, three."
It was rendered locally with Windows `System.Speech.Synthesis.SpeechSynthesizer`, using the installed
default voice, to a WAV file. It uses no provider credentials or network calls. The same bundled file
plays on supported platforms; runtime speech synthesis is not required. Its English language is stated
beside the translated test control. No real user recording is included.
