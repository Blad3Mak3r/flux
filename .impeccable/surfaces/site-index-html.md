# FLUX landing surface brief

Mode: Persuade. A static GitHub Pages landing at https://blad3mak3r.github.io/flux/.

## Audience and action

Show technicians, musicians, show designers and VJs deciding whether to try FLUX. Lead visitors to the latest GitHub
Release and offer the docs for each mode. English is the default and the EN/ES selection persists in the browser.

## Product story

FLUX offers two project types with three workflows. CUE has a timeline for building a show and a Live view for
executing cues. VJ launches and mixes visual clips in real time. Show the workflows together up front, then explain
each mode and link to its guide. Keep the clock, video mapping and specifications within reach for visitors
evaluating a setup.

## Visual direction

Set the hero on a near-black ground with a fine, receding square grid. Use the original FLUX mark, compact horizontal
navigation, a large Archivo headline, short product copy and two direct actions. Frame a panoramic screenshot of the
working FLUX interface under the headline so product evidence appears in the first desktop viewport. Use phosphor
green to highlight a few important details. Keep the page legible and the download action easy to reach at narrow widths.

The timecode demo stays with the CUE technical content. The transport, rate selector and jump show how the master
clock counts, including the 29.97 drop-frame minute boundary. Label the demo and record screenshot provenance in
`docs/landing-page.md`.
