# Surface brief: FLUX landing (site/index.html)

Mode: Persuade. Hosted on GitHub Pages (project page, https://blad3mak3r.github.io/flux/), static, no build step.

## Audience, job, action
Show technicians, musicians and show designers deciding whether to try FLUX. Action: download the latest GitHub Release (Windows installer, Linux AppImage/DEB/RPM; no macOS build yet). Secondary: GitHub, docs. English default, Spanish via selector (saved per browser).

## Proof and content
Real: Live-view screenshots in docs/screenshots (sample show data), README and docs facts. Synthetic and labelled: the browser demo readout (counts the way LTC/MTC would, drop-frame included) and the drawn Edit-timeline figure. No invented numbers, customers, benchmarks or claims. Not built: video/Art-Net cues, chasing, controller feedback, macOS build.

## Direction contract
THESIS: FLUX presented as the data sheet of an instrument. Technicians read hardware by its sheet: numbered sections, spec tables, figures, an ordering block. Refuses the SaaS hero (headline, subcopy, card row).
OWN-WORLD: Bench Instrument from DESIGN.md. Faceplate ground (hue 250), teal-black screen windows with graticule, phosphor reads, amber cues, vermilion only for live. Square, 1px rules, no glow, no cards. Archivo (wide, heavy) for headings; system sans for text; system mono only for measurements; the dot-matrix readout is drawn.
STORY: One project, one clock, every output. Visitor learns what FLUX generates (LTC, MTC, MIDI/OSC cues), sees the clock count correctly in the page, sees the real Live view, and downloads.
